### 🛡️ Sigma Rule Conversion & AI Validation
My postgraduate research project. It converts [Sigma](https://github.com/SigmaHQ/sigma) detection rules into formats for SIEMs **without native Sigma support** (Wazuh as the case study) and measures whether the detection logic survives the conversion. It includes an **AI validator** that flags semantic losses and an **AI refiner** that rewrites the rule to fix them, all behind a small web UI. Findings showed systematic, silent failures on complex rules, and the refiner measurably improved fidelity.
> `Python` · `Flask` · `Wazuh` · `Detection Engineering` · `LLM`
> 🔗 [github.com/jeamf/sigma-wazuh-converter](https://github.com/jeamf/sigma-wazuh-converter)
